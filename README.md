William's Equipment Request Form
Include a very brief summary of your project here. Be sure to include the CSS positioning technique you used, and any required instructions to use your application.
A equipment request form with a server-side list of all requests in the system. I used flexbox throughout the app for aligning the elements. To use the application go to: https://a2-williamhanlon.onrender.com/, and submit a request on the left side of the app. I also use element selectors, id selectors, and class selectors to style the website in a stylesheet. 

## Technical Achievements
- **Tech Achievement 1**: 
- This is a single-page app, where the users submit their form, and the server immediately serves the data via the table.
- **Tech Achievement 2**:
- Allows for editing of requests. When you click the edit button, it allows you to change values through the form submission menu. 

### Design/Evaluation Achievements
- **Design Achievement 1**:
1. Provide the last name of each student you conduct the evaluation with.
   Schieffer
2. What problems did the user have with your design?
    In attempting to edit a request they had added, they did not notice the content pop back up in the form, until a bit after, when they noticed the new button for cancelling the edit had appeared.
   They tried resizing the textarea input, which caused it to expand behind the table of requests, making it unable to be shrunk back to normal size.
3. What comments did they make that surprised you?
   They thought that the form and results reaching to the bottom of the screen looked a little weird, which surprised me, as seeing them take up only half the screen looked weird to me, and I changed it to the full screen.
4. What would you change about the interface based on their feedback?
    I would definitely find a way to restrict horizontal movement of the textarea field, as well as look into ways to make sure it is obvious when you are in editing mode.

 - **Design Achievement 2**:

2. What problems did the user have with your design?
   The user tried submitting the form with some required fields blank, which did not allow them to submit.
